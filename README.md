# Optimizing Revenue Leakage & Profitability in the Hospitality Sector

## Overview
This project focuses on analyzing and optimizing revenue realization for a hospitality business. Originally centered on raw "Loss," the data pipeline and dashboards have been refactored to focus on the **Profitability Index** (Revenue Realized / Revenue Generated). This shift enables better strategic decision-making by tracking how effectively potential revenue is captured.

## Project Structure
- `app.py`: Streamlit Dashboard application showcasing Key Performance Indicators (KPIs) and interactive visualizations.
- `process_data.py`: Refactored and optimized data processing pipeline. Handles dataset merging, feature engineering, and robust imputation logic without data leakage.
- `EDA.ipynb` & `Feature Engineering.ipynb`: Exploratory Data Analysis and iterative prototyping notebooks.
- `big_data_file.parquet` / `big_data_file.csv`: Final structured datasets generated by the pipeline, ready for BI tools.
- `suggestions_and_new_initiatives.md`: Proposed business strategies to mitigate revenue leakage and improve the profitability index.
- `CV_points.md`: Professional highlights of this project to include in your resume.
- `Dashboard_summer_project.twbx`: Tableau dashboard.

## Key Technical Optimizations
1. **Refactored Metrics**: Shifted from a simplistic loss calculation to a standardized `Profitability_Index`.
2. **Prevented Data Leakage**: Replaced computationally expensive and leaky Iterative Imputation strategies with grouped median imputation. Missing ratings are now filled using historical medians for the specific `property_id` and `room_category` combinations without using future knowledge like `revenue_realized`.
3. **Performance Improvements**: 
   - Moved from `.xlsx` extraction to efficient `.parquet` and `.csv` formats, vastly improving I/O performance.
   - Refactored `Feature Engineering.ipynb` logic into a single cohesive python script (`process_data.py`).

## How to Run the Dashboard
Ensure you have the required packages installed:
```bash
pip install streamlit pandas numpy plotly pyarrow fastparquet
```
Run the Streamlit app:
```bash
streamlit run app.py
```
